# CharacterStatuePatch

**CharacterStatuePatch** は、彫像（figure2）の色をを修正して素材色ではなく元キャラの色を反映させ、彫像の制作テーブルで選ばれるキャラクター候補を全キャラに拡大するパッチです。建築用途向けに作成しています。

> **重要**: この Mod は **非公開**（ワークショップ未公開）です。各自でビルドして導入してください。サポートは限定的です。

---

## 概要
- **目的**  
  - 彫像のマテリアル色を修正して素材色ではなく元キャラの色を反映させる。  
  - `figure2`（彫像）生成時の候補範囲を全キャラに拡大し、重み付きで選択するようにする。  
- **想定用途**: 建築・装飾用の彫像を作成・配置する Mod と組み合わせて利用。  
- **公開状況**: 非公開（ソースはリポジトリにありますが、配布は行っていません）。

---

## 注意事項
- **この Patch が当たっているデータでないと元の色は反映されません。**  
  - つまり、この Mod で修正した彫像を配置する別の Mod を配布する場合、利用側は本 Mod を前提 Mod とするか、修正ロジックを自身の Mod に組み込む必要があります。  
- ゲームのアップデートや他 Mod との競合で動作が変わる可能性があります。導入は自己責任でお願いします。  
- 大きな変更を行う Mod と併用する場合は、事前にバックアップを取ることを推奨します。
---

## インストール
1. ビルド済 DLL（`CharacterStatuePatch.dll`）を用意する。  
2. ゲームの Mod 配置先（例: `Elin/Package/`）にフォルダを作成し、DLL を配置する。  
3. ゲームを起動して動作を確認する。

> ワークショップ公開はしていません。配布する場合は README と LICENSE を同梱してください。

---

## ビルド方法
1. リポジトリをクローンまたはソースを取得。  
2. 参照に `BepInEx` と `HarmonyLib`、およびゲームのアセンブリを追加。  
3. Visual Studio でソリューションを開くか、`dotnet` でビルド。

```bash
cd CharacterStatuePatch
dotnet build -c Release
```

- Visual Studio を使う場合はターゲットフレームワークと参照パスをゲーム環境に合わせてください。

---

## 使い方
- 導入するだけでパッチが適用されます。  
- 彫像を制作・配置して、色や候補範囲が期待通りか確認してください。
