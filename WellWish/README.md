# WellWish

**WellWish** は、井戸などの飲み水で「願い」が再びかなえられる状態になったときに通知を出す軽量プラグインです。  
ワークショップ未公開のため、各自でビルドして導入してください。

> **注意**: この Mod は **サポート対象外** です。バグ報告や要望には対応できません。

---

## 概要
- **目的**: プレイヤーが「井戸の願い」を再度行える状態になったときにダイアログで通知します。  
- **動作タイミング**: 年の切り替え、プレイヤー読み込み、キーアイテム取得などのタイミングで判定・通知を行います。  
---

## インストール（利用者向け）
### 推奨（ビルド済 DLL を導入する場合）
1. `WellWish.dll`（ビルド成果物）を用意する。  
2. ゲームの Mod 配置先（例: `Elin/Package/`）にフォルダを作成し、`WellWish.dll` を配置する。  
3. ゲームを起動して動作を確認する。

### ワークショップ
- ワークショップには公開していません。

---

## ビルド方法
1. リポジトリをクローンまたはソースを取得。  
2. 必要な NuGet パッケージ（`BepInEx`, `HarmonyLib` 等）を参照する。  
3. Visual Studio でソリューションを開くか、`dotnet` でビルドする。

```bash
# 例: プロジェクトフォルダに移動してビルド
cd WellWish
dotnet build -c Release
# 出力 DLL をゲームの Mods 配下へコピー
```

- Visual Studio を使う場合はターゲットフレームワークや参照パスをゲーム環境に合わせて設定してください。
