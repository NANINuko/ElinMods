# WorldWeave

**WorldWeave** は、Elinの野外マップ生成時に、あらかじめ作成された建築物や地形をランダムに配置するModです。

ゲーム内で作成したマップをテンプレートとして利用でき、プログラミング不要で独自の建築物や遺跡などを野外マップの生成候補に追加できます。

また、他のModからテンプレートを追加する仕組みを備えており、WorldWeaveを利用した拡張Modを作成することも可能です。

## 主な機能

- 野外マップ生成時のテンプレート自動配置
- 出現確率・抽選重み・配置数の設定
- ゾーンタイプ・バイオームによる出現制限
- 1つのマップデータから複数のテンプレートを登録
- 複数テンプレートの重複配置防止
- キャラクターや重要アイテムなどの保護
- 外部Modからのテンプレート追加
- 永続キャッシュによるテンプレート読み込みの高速化
- Mod再読み込み時のテンプレート自動更新

## インストール

### Steam Workshop（推奨）

Steam Workshopからサブスクライブし、ゲーム内のMod管理画面で有効化してください。

- [Steam Workshop - 作者の公開Mod一覧](https://steamcommunity.com/profiles/76561199610393202/myworkshopfiles/)

### 手動インストール

ビルド済みのMod一式を `Elin/Package/` 配下に配置し、ゲーム内のMod管理画面で有効化してください。

ソースコードから導入する場合は、各自の開発環境に合わせて参照先を設定し、ビルドしてください。

- [GitHub - ElinMods](https://github.com/NANINuko/ElinMods)

## 使い方

Modを有効化した状態で野外マップを生成すると、登録されているテンプレートの中から条件を満たすものが抽選され、マップ内に配置されます。

対象となるゾーンは以下の2種類です。

- `Zone_Field`
- `Zone_Wilds`

テンプレートの配置はマップ生成時に行われます。生成済みのマップに入るだけでは、新たなテンプレートは配置されません。

また、出現確率や配置条件によっては、テンプレートが一切配置されない場合もあります。

## Mod設定

BepInExの設定ファイルから、配置数や出現率、キャッシュに関する設定を変更できます。

設定ファイル名：`com.naninuko.elin.worldweave.cfg`

### General

| 項目 | 初期値 | 説明 |
|---|---:|---|
| MaxTemplatesPerMap | 1 | 1マップあたりのテンプレート配置数の上限。最低値は1。 |

### Spawn

| 項目 | 初期値 | 説明 |
|---|---:|---|
| SpawnChanceMultiplier | 1.0 | 全テンプレートに適用される出現確率の倍率。 |

`SpawnChanceMultiplier` の設定例：

- `0.0`：出現率0%
- `0.5`：通常の半分
- `1.0`：通常通り
- `2.0`：通常の2倍
- `10.0`：通常の10倍

倍率適用後の出現確率は0～100%の範囲に制限されます。

### Cache

| 項目 | 初期値 | 説明 |
|---|---:|---|
| UsePersistentCache | true | 永続キャッシュを使用する。 |
| PurgeOldCachesOnReload | true | Mod再読み込み時に古いキャッシュを削除する。 |
| CacheRetentionDays | 30 | キャッシュの保持日数。0以下で日数による削除を無効化する。 |
| LogCacheStatisticsOnReload | true | Mod再読み込み時にキャッシュの統計情報をログに出力する。 |

### Debug

| 項目 | 初期値 | 説明 |
|---|---:|---|
| EnableDetailedLogs | false | テンプレートの読み込み・配置・キャッシュに関する詳細ログを出力する。 |

通常は詳細ログを無効にしておくことを推奨します。

## テンプレートの追加

### 基本構成

テンプレートは、Elinからエクスポートしたマップデータ（`.z`）と、テンプレートの設定ファイル（`.json`）の組み合わせで構成されます。

`WorldWeave.dll` と同じ階層にある `Templates` フォルダに、同名の `.z` ファイルと `.json` ファイルを配置してください。

```text
WorldWeave/
├── WorldWeave.dll
└── Templates/
    ├── abandoned_house.z
    ├── abandoned_house.json
    ├── ruins.z
    └── ruins.json
```

`Templates` フォルダ直下のファイルが読み込み対象となります。サブフォルダ内のテンプレートは読み込まれません。

### JSON設定例

以下は、10×12マスの建築物をテンプレートとして登録する例です。

```json
{
    "enabled": true,
    "spawnChance": 0.1,
    "weight": 1,
    "maxPerMap": 1,
    "replaceExisting": true,
    "zoneTypes": [
        "Zone_Field",
        "Zone_Wilds"
    ],
    "biomes": [],
    "activeRect": {
        "x": 10,
        "z": 10,
        "w": 10,
        "h": 12
    }
}
```

### 設定項目

| 項目 | 初期値 | 説明 |
|---|---|---|
| enabled | true | テンプレートの有効・無効。 |
| spawnChance | 0.1 | 配置候補に選ばれる確率。0.0～1.0で指定する。 |
| weight | 1 | 配置候補間の抽選重み。最低値は1。 |
| maxPerMap | 1 | 同一テンプレートの1マップあたりの配置上限。0以下で個別上限なし。 |
| replaceExisting | true | 配置範囲内にある、マップ生成時に追加された既存Cardの削除処理を行う。 |
| zoneTypes | [] | 配置を許可するゾーンタイプ。空配列で制限なし。 |
| biomes | [] | 配置を許可するバイオームID。空配列で制限なし。 |
| activeRect | 自動検出 | 元マップから切り出す範囲。 |
| variants | [] | 同一マップデータから複数のテンプレートを登録するための設定。 |

省略された項目には初期値が使用されます。

なお、`zoneTypes` を空配列にした場合でも、WorldWeave自体の対象ゾーンである `Zone_Field` と `Zone_Wilds` 以外には配置されません。

### activeRect

元マップからテンプレートとして使用する範囲を指定します。

```json
"activeRect": {
    "x": 10,
    "z": 20,
    "w": 8,
    "h": 6
}
```

| 項目 | 説明 |
|---|---|
| x | 切り出し開始位置のX座標 |
| z | 切り出し開始位置のZ座標 |
| w | X方向のサイズ |
| h | Z方向のサイズ |

上記の例では、座標 `(10, 20)` から8×6マスの範囲をテンプレートとして使用します。

`activeRect` を省略した場合は、床・壁・家具・キャラクターなどが存在する範囲から自動的に切り出し範囲を決定します。

意図しない地形やオブジェクトの取り込みを防ぐため、基本的には範囲を明示的に指定することを推奨します。

## バリエーション（variants）

`variants` を使用することで、1つの `.z` ファイルから複数の独立したテンプレートを登録できます。

複数の建築物を1枚のマップにまとめて作成し、それぞれ異なる出現確率や配置条件を設定することが可能です。

### 設定例

```json
{
    "enabled": true,
    "spawnChance": 0.1,
    "weight": 1,
    "maxPerMap": 1,
    "replaceExisting": true,
    "zoneTypes": [
        "Zone_Field",
        "Zone_Wilds"
    ],
    "biomes": [],
    "variants": [
        {
            "id": "house",
            "spawnChance": 0.2,
            "weight": 2,
            "activeRect": {
                "x": 10,
                "z": 10,
                "w": 12,
                "h": 10
            }
        },
        {
            "id": "well",
            "spawnChance": 0.3,
            "maxPerMap": 2,
            "activeRect": {
                "x": 30,
                "z": 10,
                "w": 3,
                "h": 3
            }
        },
        {
            "id": "ruins",
            "spawnChance": 0.05,
            "activeRect": {
                "x": 50,
                "z": 10,
                "w": 15,
                "h": 15
            }
        }
    ]
}
```

この例では、家・井戸・遺跡の3種類が、それぞれ独立したテンプレートとして登録されます。

### バリエーションごとに設定可能な項目

| 項目 | 説明 |
|---|---|
| id | バリエーションの識別ID |
| enabled | バリエーションの有効・無効 |
| spawnChance | 出現確率 |
| weight | 抽選重み |
| maxPerMap | 1マップあたりの配置上限 |
| replaceExisting | 既存Cardの削除処理 |
| activeRect | 切り出し範囲 |

省略された設定は、原則としてJSONの共通設定を引き継ぎます。

- `id` を省略した場合は `variant_0` などのIDが自動的に割り当てられます。
- `variants` を省略した場合は `default` というIDのテンプレートが登録されます。
- 共通設定の `enabled` が `false` の場合、すべてのバリエーションが無効になります。
- `zoneTypes` と `biomes` は共通設定でのみ指定できます。
- `maxPerMap` はバリエーション単位で適用されます。

なお、テンプレート全体の配置数はMod設定の `MaxTemplatesPerMap` によって制限されます。

## 拡張Modの作成

WorldWeave本体を変更することなく、別のModからテンプレートを追加できます。

独自の建築物や遺跡をまとめたテンプレートパックなどを作成・配布する場合は、こちらの方法を推奨します。

### フォルダ構成

```text
MyWorldWeavePack/
├── package.xml
├── WorldWeave.json
└── Templates/
    ├── mypack_house.z
    ├── mypack_house.json
    ├── mypack_ruins.z
    └── mypack_ruins.json
```

通常のElin用Modに加え、以下の2つを用意してください。

- `WorldWeave.json`
- `Templates` フォルダ

### WorldWeave.json

Modのルートフォルダに配置する識別用ファイルです。

```json
{}
```

このファイルはWorldWeave対応Modであることを示すために使用されます。ファイルの内容は読み込まれないため、空のJSONオブジェクトで問題ありません。

WorldWeaveは、有効化されているModの中から `WorldWeave.json` が存在するものを検索し、そのModの `Templates` フォルダ内にあるテンプレートを読み込みます。

テンプレートの設定方法は、WorldWeave本体に追加する場合と同じです。

テンプレート追加のために独自のDLLを作成する必要はありません。

### テンプレートIDの重複について

テンプレートは、JSONファイル名とバリエーションIDの組み合わせによって識別されます。

同一の組み合わせが複数のModに存在する場合、後から読み込まれたテンプレートによって上書きされます。

意図しない競合を防ぐため、ファイル名にはMod固有の接頭辞などを付けることを推奨します。

## テンプレートの配置仕様

### 出現確率と抽選重み

テンプレートの抽選は、以下の順序で行われます。

1. ゾーンタイプ・バイオーム・配置上限などの条件を確認する。
2. 各テンプレートの `spawnChance` に全体倍率を適用し、配置候補を抽選する。
3. 配置候補の中から `weight` に基づいてテンプレートを選択する。
4. 選択されたテンプレートの配置を試みる。
5. 配置に失敗した場合は、残りの候補から再抽選する。

例えば、出現確率の抽選を通過したテンプレートAとBの `weight` がそれぞれ1と3の場合、選択される比率は1：3となります。

`spawnChance` は最終的な配置確率ではなく、配置候補に入るための確率です。

### 配置位置

テンプレートは、主にマップ中央付近に配置されます。

複数のテンプレートを配置する場合は、既に配置されたテンプレートの範囲と重複しないように配置位置を探索します。

テンプレートのランダム回転は行われません。

### 既存オブジェクトの保護

テンプレート配置時に重要なオブジェクトが削除されることを防ぐため、保護処理を行っています。

主な保護対象は以下の通りです。

- キャラクター
- グローバルCard
- プレイヤーが作成したもの
- NPCの所有物
- 重要・ユニーク・強力なアイテム
- 贈り物・落とし物・盗品・コピー品
- プレイヤーのパーティーに所属していたCard
- 今回のマップ生成処理で追加されたものとして記録されていないCard

`replaceExisting` が `true` の場合でも、これらの保護対象は削除処理から除外されます。

ただし、配置範囲内の植物は `replaceExisting` の設定にかかわらず除去されます。また、床や壁などの地形はテンプレートによって変更されます。

## キャッシュ

WorldWeaveは、元のマップデータから切り出したテンプレートを永続キャッシュとして保存します。

初回読み込み時にキャッシュを作成し、次回以降は保存済みのデータを再利用することで、マップデータの展開や切り出し処理を省略します。

### キャッシュの更新

以下の情報を基に、元ファイルの変更を検出します。

- ファイルパス
- ファイルサイズ
- 最終更新日時

`.z` または `.json` ファイルが変更された場合は、新しいキャッシュが作成されます。

新しいキャッシュの保存に成功すると、同一テンプレートの古い世代のキャッシュは自動的に削除されます。

### キャッシュの保存先

キャッシュは、ゲームのModデータ保存先にある `WorldWeaveCache` フォルダに保存されます。

```text
WorldWeaveCache/
└── テンプレート名/
    └── バリエーションID/
        └── キャッシュ識別子/
```

キャッシュは元のテンプレートから再生成可能です。

テンプレートの読み込みに問題が発生した場合は、ゲームを終了した状態でキャッシュフォルダを削除し、再生成を試してください。

## 注意事項

- テンプレートはマップ生成時に配置されます。
- 大きすぎるテンプレートは、配置範囲がマップ外にはみ出す場合があります。
- テンプレートの数やサイズによっては、読み込み時間・メモリ使用量・キャッシュ容量が増加します。
- カスタム素材や家具などを使用したテンプレートには、それらを追加するModが別途必要となる場合があります。
- 他のマップ生成系Modとの組み合わせによっては、意図しない配置や競合が発生する可能性があります。
- 導入前にセーブデータのバックアップを推奨します。
